Guiado por la documentación oficial de Rust, estoy aprendiendo el lenguaje como una alternativa para construir aplicaciones más ligeras, ya que Java consume muchos recursos.

En esta primera sesión aprendí lo básico sobre la instalación de Rust en un entorno Linux y un hello world básico. La doc también enseña la estructura inicial de la función `main` y, un poco más adelante, cómo iniciar un proyecto usando cargo. Muy satisfactorio, esta primera experiencia, porque la estructura me recuerda mucho a los proyectos en Java y Node.

Tuve que reinstalar Go para que funcionara, así como otras dependencias. Después de eso fue un éxito, solo seguir la documentación con los comandos iniciales. En la sesión 'Hello, Cargo!', me parece que es donde las cosas tienen más sentido, cuando se llevan a un entorno de desarrollo profesional.

Dejo aquí algunos comandos que son bastante útiles, sacados de la propia documentación:

> We can create a project using `cargo new`.</br>
We can build a project using `cargo build`.</br>
We can build and run a project in one step using `cargo run`.</br>
We can build a project without producing a binary to check for errors using `cargo check`.

Además, como entrenamiento de hábito, pretendo usar al menos 20 minutos diarios para ir avanzando en la doc. No tengo mucha prisa y a este ritmo creo que no demandará un esfuerzo innecesario.

Este es el sitio de la doc: <https://doc.rust-lang.org/book/ch01-00-getting-started.html>
