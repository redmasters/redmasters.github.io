Guided by the official Rust documentation, I'm learning the language as an alternative for building lighter applications, since Java consumes a lot of resources.

In this first session I learned the basics about installing Rust on a Linux environment and a basic hello world. The doc also teaches the initial structure of the `main` function and, a bit further ahead, how to start a project using cargo. Very satisfying, this first experience, because the structure reminds me a lot of Java and Node projects.

I had to reinstall Go to make it work, as well as other dependencies. After that it was a success, just follow the documentation with the initial commands. In the 'Hello, Cargo!' session, it seems to me that things make more sense when taken into a professional development environment.

Leaving here a few commands that are quite useful, taken from the documentation itself:

> We can create a project using `cargo new`.</br>
We can build a project using `cargo build`.</br>
We can build and run a project in one step using `cargo run`.</br>
We can build a project without producing a binary to check for errors using `cargo check`.

Besides that, as a habit-building exercise, I intend to spend at least 20 minutes a day moving forward in the doc. I'm not in a hurry and at this pace I believe it won't demand unnecessary effort.

Here is the doc site: <https://doc.rust-lang.org/book/ch01-00-getting-started.html>
